# Конвертер изображений в PDF

Drag & Drop веб-приложение для загрузки изображений с последующей конвертацией в PDF файл.

## Особенности

- **Drag & Drop интерфейс**: Легкая загрузка изображений перетаскиванием
- **Поддержка форматов**: PNG, JPG, JPEG
- **Предпросмотр**: Миниатюры загруженных изображений
- **Адаптивный дизайн**: Работает на всех устройствах
- **Тёмная тема**: Современный минималистичный интерфейс
- **Информативная консоль**: Все операции логируются в консоли браузера

## Использование

1. **Загрузка изображений**:
   - Перетащите файлы в выделенную зону
   - Или нажмите "Выбрать файлы"

2. **Проверка загруженных файлов**:
   - Откроется консоль браузера (F12 → Console)
   - Будут выведены данные о каждом изображении
   - Можно увидеть миниатюры загруженных файлов

3. **Очистка**:
   - Кнопка "Очистить все изображения" удаляет все загруженные файлы

## Разработка

Приложение находится в режиме разработки. В настоящее время:
- Изображения только выводятся в консоль браузера
- Бэкенд для конвертации в PDF пока не интегрирован
- Все данные обрабатываются локально

Для тестирования используйте любые изображения формата PNG, JPG или JPEG.
